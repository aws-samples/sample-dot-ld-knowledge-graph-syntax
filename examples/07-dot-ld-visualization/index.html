DOT-LD Syntax

Define your system structure right in your markdown!

Configuration Block (hidden in output):

::config
// Style: type: shape, color, size
equipment: round-rectangle, #4A90E2, 120

// Entities: name: type=...
ChillerSystem: type=equipment
::

Inline References:

The [[ChillerSystem]] includes...

Relationships (hidden in output):

::rel Source -> Target [label] ::
// Arrow directions: ->, <-, <->
